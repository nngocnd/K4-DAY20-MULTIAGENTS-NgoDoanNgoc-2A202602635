---
name: implement-regression-testing
description: Use when fixing bugs or modifying existing code to ensure stability and compliance with testing rules.
---
<body>
1. Create a `tests/test_regressions.py` file for any bug fixes.
2. Implement at least one test function per bug fixed, ensuring a minimum of 3 tests total.
3. Verify that all tests pass using `pytest` before finalizing the code.
4. Ensure the test file is included in the final submission if required by the task rules.
5. Self-check: Did I add the required number of tests? Does the test file pass? Is the file named correctly?
</body>
